# Debug 面板设计文档（day22）

## 背景与目标

项目已具备可观测性：每次请求生成一个 Trace，记录 Agent 的每一步（LLM 调用、工具调用、token、耗时），存于 `logs/traces.jsonl` + 内存环形缓冲，`GET /debug/traces` 接口可查。

**但 Trace 数据只以 JSON 形式存在，没有可视化界面。** 面试时无法直观展示 Agent 的"幕后思考过程"，开发调试时也只能对着 JSON 看。

**目标：** 做一个 Debug 可视化面板，实现：
1. 面试展示：让面试官亲眼看到 Agent 一步步"思考 → 调工具 → 拿结果 → 再思考 → 回答"
2. 开发调试：快速定位一次请求慢在哪步、哪个工具失败、烧了多少 token

## 设计决策

**独立页面，不嵌入主前端。** 原因：
- 主前端 index.html 是用户自制的 TRAVERSO 暗色主题作品，面试要讲，不能改乱
- 职责单一：主界面 = 用户聊天；Debug 台 = 看幕后
- 面试时开两个标签页对比，展示力强

## 页面结构（左右分栏）

```
┌ 左栏：最近请求列表 ┐      ┌ 右栏：Trace 详情/重放 ┐
│ 每行一条：            │      │ ▶播放 ⏸暂停 ⏮⏭步进   │
│  query + 耗时 + token │      │ 速度 [1x][2x][4x]   │
│  ──────────────       │      ├────────────────────┤
│  "我想去呼和浩特"      │      │ ● 第N轮 · LLM 思考   │
│  30s · 12080tok · 3轮│      │ ● 🔧 get_weather     │
│  "对比成都和大理"      │      │   呼和浩特 → 未找到  │
│  8s  ·  5100tok · 2轮│      │ ● 🔧 search_spots    │
│  ...                 │      │ ● 🔧 get_profile     │
│                      │      ├── 统计卡 ──────────┤
│                      │      │ 3轮LLM · 6工具       │
│                      │      │ 12080 tok · 30s     │
└──────────────────────┘      └────────────────────┘
```

## 功能清单

| 功能 | 说明 |
|------|------|
| 请求列表 | 最近 20 条，时间倒序，显示 query、耗时、token、轮数 |
| Trace 详情 | 点某条，右侧按时间顺序展示所有 steps |
| 重放 | 播放/暂停/上一步/下一步/速度(1x/2x/4x)，当前步高亮 + 自动滚动 |
| 状态区分 | llm_call 紫、tool_call 青；失败/未找到标红 |
| 统计卡 | 当前 Trace 的 LLM 次数、工具数、总 token、总耗时 |
| 空状态 | 无 Trace 时显示"还没有记录，先去用一次 Agent" |

## 数据流

```
前端 fetch GET /debug/traces?limit=20
  → 渲染左栏列表
  → 点击某条，取得 steps 数组
  → 重放 = 定时器按当前步数渲染右栏
```

**后端零改动**（接口已存在）。

## 文件改动

| 文件 | 动作 |
|------|------|
| `static/debug.html` | 新增，整个面板（纯 HTML/CSS/JS，沿用 TRAVERSO 暗色风格） |
| `app/main.py` | 加 `@app.get("/debug")` 返回 debug.html |

不改：agent_loop.py、trace.py、index.html。

## 技术要点（学习点）

1. 前端 `fetch` + `async/await` 调接口
2. `setInterval` / 手动步进实现"播放"
3. JSON steps → HTML 渲染（模板字符串或 createElement）
4. 状态徽章：按 step.type 区分样式（llm_call / tool_call）

## 验收标准

- [ ] 访问 `/debug` 能看到面板，样式与 TRAVERSO 一致
- [ ] 用 Agent 聊一句后，列表出现新记录
- [ ] 点击记录，右侧逐步展示 steps，区分 LLM 思考和工具调用
- [ ] 播放按钮能自动逐条推进，当前步高亮
- [ ] 无数据时显示空状态提示
